## Custom

Stored in `localStorage` key `omp-custom-theme` (accent, background, dark/light, static/flow). Survives reload.

Also: font preset (`omp-typography-config`), chat size (`omp-font-size`), UI scale (`omp-ui-scale`), motion (`omp-motion-prefs`).
